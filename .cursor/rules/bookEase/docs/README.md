# Agile Project — Daily Docs

Thư mục này chứa **nhật ký từng ngày làm việc** của project BookEase.

- Khi bạn nói **`start agile project ngày <NN>`**, AI (PM/Tech Lead) sẽ tạo file `day-<NN>.md` ở đây, gồm: Standup, task hôm nay, mục đích, skill mapping, các bước thực hiện, Definition of Done, và AI workflow cần dùng.
- Khi bạn nói **`kết thúc ngày`**, AI cập nhật phần "Kết quả cuối ngày" (verify PASS/FAIL + carry-forward) vào đúng file ngày đó.

Template chi tiết xem `../context/agile-context.mdc` (Mục 6).
